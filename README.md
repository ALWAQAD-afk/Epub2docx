# Epub2docx
أخذ ملفات بصيغة ( epub ) وتحويلها إلى ملفات docx بصيغة صحيحة. 
# محول كتب التراث إلى Word (نسخة EPUB لـ GitHub Pages)

أداة ويب خفيفة وسريعة تعمل بنسبة **100% داخل المتصفح** لتحويل ملفات الكتب الإلكترونية بصيغة **EPUB** إلى مستندات **Word (.docx)** منسقة بدقة وفق معايير الطباعة التراثية المعتمدة (تنسيق موقع تراث).

## ✨ المميزات

- **بدون سيرفر نهائيًا**: تعمل بالكامل على **GitHub Pages** ومكتوبة بتقنيات الويب القياسية (HTML5, JSZip, docx.js).
- **خصوصية وأمان 100%**: لا يُرفع ملف الكتاب إلى أي خادم، بل تتم كل المعالجة محليًا في ذاكرة المتصفح.
- **التنسيق الذهبي (Golden Settings)**:
  - خط المتن: Traditional Arabic (14pt)، محاذاة مضبوطة كشيدة (Justified).
  - خط العناوين: Traditional Arabic (17pt)، عريض (Bold)، توسيط.
  - هوامش احترافية وحجم صفحة قياسي A4.
  - إعدادات التوافق مع إصدارات Word الحديثة (OpenType وتوافقية Word 2013-2021).
  - حقول ترقيم صفحات ديناميكية وحية في تذييل كل صفحة.
  - صفحة غلاف وعنوان تلقائية.

---

## 🚀 طريقة التفعيل على GitHub Pages (خطوة بخطوة للمبتدئين)

1. أنشئ مستودعًا جديدًا على حسابك في GitHub (مثلاً باسم `epub2docx` أو حدّث مستودعك الحالي).
2. ارفع ملفات هذا المجلد (`index.html` و `.nojekyll` و `README.md`) عبر الضغط على **Add file** ثم **Upload files**.
3. اضغط على **Commit changes** لحفظ الملفات.
4. اذهب إلى تبويب **Settings** في مستودعك، ثم من القائمة الجانبية اختر **Pages**.
5. تحت قسم **Build and deployment** > **Branch**، اختر الفرع **main** والمجلد `/ (root)` ثم اضغط **Save**.
6. خلال دقيقة واحدة، سيظهر لك في أعلى الصفحة رابط موقعك المباشر:
   `https://<YOUR_USERNAME>.github.io/<REPO_NAME>/`
